📈 MPT Portfolio Manager

จัดพอร์ตตามทฤษฎี Modern Portfolio Theory (Markowitz mean–variance) — คำนวณในเครื่องคุณทั้งหมด ข้อมูลไม่ถูกส่งไปไหน

1ข้อมูลราคาย้อนหลัง

รับ 2 แบบ: ไฟล์รวม (คอลัมน์ date + ราคาปิดรายสินทรัพย์ จาก fetch_yahoo.py/โบรกเกอร์) หรือ ไฟล์ History รายตัวจากเว็บ Yahoo หลายไฟล์ (BLC.BK.csv, SISB.BK.csv, ...) เดี๋ยวรวมให้เอง
ยังไม่มีข้อมูล — ใส่ข้อมูลราคาก่อน แล้วส่วนล่างจะปลดล็อกให้กดคำนวณ
ปุ่มดึงข้อมูลใช้ไม่ได้ (403/CORS)? — 2 ทางแก้ใน 1 นาที
ทาง 1 · ดาวน์โหลดจากหน้าเว็บ Yahoo (ไม่ต้องใช้โปรแกรมอะไรเลย)
เปิด finance.yahoo.com → ค้นหุ้นเช่น BLC.BK → แท็บ Historical Data → เลือกช่วง 3Y → กด Download จะได้ไฟล์เช่น BLC.BK.csv — ทำครบทุกตัวแล้วเลือกอัปโหลดทุกไฟล์พร้อมกันในช่องด้านบน โปรแกรมรวม + เรียงวันที่ให้อัตโนมัติ

ทาง 2 · รันสคริปต์บนเครื่อง (ครั้งเดียวได้ไฟล์เดียวครบทุกตัว) — ต้องมี Python:
python fetch_yahoo.py BLC.BK SISB.BK SPALI.BK AIT.BK DCC.BK LHHOTEL.BK SECURE.BK INETREIT.BK PSL.BK VAYU1.BK --out prices.csv
แล้วอัปโหลด prices.csv ที่ได้ (สคริปต์อยู่ในโฟลเดอร์เดียวกับไฟล์นี้ใน repo)
