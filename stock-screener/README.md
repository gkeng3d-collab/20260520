# SET Stock Screener — คัดกรองหุ้นสำหรับเทรด

สคริปต์คัดกรองหุ้น SET จากไฟล์ export `listSET_YYYYMMDD.xlsx` (ชีท `ALL` — 1 แถวต่อ 1 หุ้น,
~1,666 คอลัมน์ตัวชี้วัด พร้อมชีท `Metadata` อธิบายคอลัมน์)

## วิธีใช้

```bash
pip install pandas openpyxl numpy
python3 screen_set_stocks.py data/listSET_20260730.xlsx output/watchlist_20260730.xlsx
```

ผลลัพธ์เป็นไฟล์ Excel 8 ชีท: เกณฑ์ที่ใช้, **ภาพตลาด & กลุ่ม** (market breadth จากหุ้นทั้งไฟล์ +
สรุปโหมดตลาด + ตารางแรงหมุนรายกลุ่ม), Top 20 รวมทุกกลยุทธ์, รายชื่อเต็มของแต่ละกลยุทธ์ (A–D)
และชีท "ย้ายโซน RSI" (แถวเขียว = โซนเพิ่งฟื้น, แถวแดง = โซนเพิ่งอ่อนลง)
ทุกตารางมีคอลัมน์ "ชนะกลุ่ม 20 วัน %" = ผลตอบแทนหุ้นลบมัธยฐานกลุ่มตัวเอง (ข้อมูลประกอบ ไม่คิดในคะแนนรวม)

## เกณฑ์คัดกรอง

**Universe** — ตัดหุ้นที่เทรดยากออกก่อน: คุณภาพข้อมูลผ่าน (`data_quality_ok`),
มูลค่าซื้อขายเฉลี่ย 10 และ 25 วัน ≥ 10 ล้านบาท/วัน, มูลค่าตลาด ≥ 3 พันล้านบาท,
free float ≥ 15%, ราคา ≥ 1 บาท

| กลยุทธ์ | แนวคิด | เงื่อนไขหลัก |
|---|---|---|
| **A-Momentum** | ขี่เทรนด์ขาขึ้นที่แข็งกว่าตลาด | CDC เขียว, ราคาเหนือ EMA26 (ไม่เกิน +12%), MA25>MA60, RSI วัน 55–78 + สัปดาห์ >50, MACD hist บวก, ADX≥20 & DI+>DI-, RS rank 20 วัน ≥65, ไม่มี bearish divergence |
| **B-Breakout** | เข้าเมื่อเพิ่งทะลุฐานพร้อมวอลุ่ม | ทะลุ high 60/100 วัน + วอลุ่ม ≥1.5 เท่า หรือสัญญาณใหม่ (CDC/MACD/EMA26 เพิ่งตัดขึ้น) + แท่งล่าสุดบวก |
| **C-Pullback** | ซื้อย่อในขาขึ้นใหญ่ | RSI สัปดาห์ยัง >50 แต่รายวันย่อมาใกล้ EMA26 (−6% ถึง +3%), ยืนเหนือ MA60/MA100, ผลตอบแทน 60 วันบวก |
| **D-MCDX** | ตามรอยเจ้าเก็บของ | MCDX แถบแดง (แรงซื้อรายใหญ่) ≥ 10 และเพิ่มขึ้นเทียบ 5 แท่งก่อน, วันล่าสุดไม่โดนทุบแรง |

**RSIzone**: zone1 = อ่อนทั้งวัน+สัปดาห์ | zone2 = วันเด้ง สัปดาห์ยังอ่อน | zone3 = แข็งทั้งคู่ |
zone4 = วันย่อในขาขึ้นสัปดาห์ (โซนตั้งรับ) — ทุกตารางแสดงโซน + การย้ายโซนล่าสุด และมีธงเตือน
"แรงรายใหญ่แผ่วลง" (ΔMCDX 5 แท่ง ≤ −8) กับ "โซน RSI เพิ่งอ่อนลง" ให้อัตโนมัติ

**คะแนนรวม (composite 0–100+)** ใช้จัดอันดับ: `SCORE` จากไฟล์ 25% + RS rank 20/60 วัน 30% +
ความแรงเทรนด์ (ADX) 10 + โมเมนตัมสัปดาห์ 5 + MACD เร่งขึ้น 5 + วอลุ่มเข้า 10 +
แรงซื้อรายใหญ่ (MCDX) 10 − โทษ divergence / ราคายืดไกลเส้นค่าเฉลี่ย

ทุกตัวมีระดับตัดขาดทุนอ้างอิง 2×ATR ใต้ราคาปิด และแนวรับ EMA26 ให้ในตาราง
พร้อมธงเตือน เช่น งบออกภายใน 10 วัน, ราคายืดตัว, RSI สูง, beta สูง
